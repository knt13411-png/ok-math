# OK수학 · 초·중등 수학 개인별 관리 웹앱

초등학생·중학생 한 명 한 명의 **진도 · 평가 · 오답 · 출결/과제**를 기록하면
취약 단원을 자동으로 찾아 주고, 학부모에게 보낼 **학습 리포트**까지 만들어 주는 웹앱입니다.

- 설치 없이 `index.html`만 열면 동작합니다 (서버·DB·로그인 불필요).
- 데이터는 브라우저 `localStorage`에 저장되고, JSON 파일로 백업/복원할 수 있습니다.
- 외부 라이브러리 없이 HTML · CSS · 바닐라 JavaScript로 작성했습니다 (글꼴만 Pretendard CDN 사용).
- **앱으로 설치(PWA)**: 휴대폰 홈 화면이나 PC에 설치하면 전체 화면 앱으로 열리고, 인터넷이 없어도 동작합니다.
- **보기 편한 화면**: 다크 모드, 큰 글씨 모드, 모바일 하단 탭 메뉴, 높은 글자 대비(WCAG AA).

## 주요 기능

| 화면 | 내용 |
| --- | --- |
| 대시보드 | 학생 수, 평균 진도율, 최근 평균 점수, 미해결 오답 합계 / **관리가 필요한 학생** 자동 추출 / 학생별 현황표 |
| 학생 관리 | 학생 등록·수정·삭제(초1~초6, 중1~중3), 이름·학교 검색, 학년·학교급(초등/중등 전체) 필터, 학생 카드(진도율·최근 평균·추세·알림) |
| 개요 | 핵심 지표 4개, 성적 추이 그래프(SVG), 보완이 필요한 단원 Top 5, 관리 알림 |
| 진도 | 2022 개정 교육과정 초1~초6(학기 순 단원) · 중1~중3(대단원)별 상태(미시작/진행 중/완료) + 이해도(1~5), 이전 학년은 복습 · 다음 학년은 선행으로 기록 |
| 평가 | 날짜·유형·단원·점수/만점 기록(100점 환산), 수정·삭제, 성적 추이 그래프 |
| 오답노트 | 단원·출처·원인(개념 부족/계산 실수/문제 이해/시간 부족) 기록, 해결 체크, 원인별 분석 |
| 수업일지 | 출결(출석/지각/결석), 과제(완료/일부/미완료), 수업 내용 기록, 출석률·과제 수행률 |
| 리포트 | 진도·평가·오답·출결·보완 단원·지도 계획 자동 작성 + 선생님 코멘트, **문자용 텍스트 복사**, 인쇄/PDF 저장 |
| 데이터 관리 | JSON 백업 내보내기/가져오기, 샘플 학생 6명 추가, 전체 초기화, 앱 설치 안내 |

### 자동 분석 규칙

- **취약 단원**: 단원 평균 70점 미만, 미해결 오답 수, 이해도 2 이하를 가중 합산해 순위를 매깁니다.
- **관리 알림**
  - 높음: 최근 3회 평균이 이전 3회보다 10점 이상 하락 / 최근 평균 60점 미만
  - 중간: 미해결 오답 5개 이상 / 최근 3회 수업 중 결석 2회 이상 / 과제 연속 미완료
  - 낮음: 14일 이상 기록 없음
- **지도 계획**: 가장 취약한 단원과 가장 많은 오답 원인에 맞춘 문장을 자동으로 제안합니다.

## 앱으로 설치하기

| 기기 | 방법 |
| --- | --- |
| 안드로이드 · PC (Chrome, Edge, 삼성 인터넷) | 사이드바의 **앱으로 설치하기** 버튼, 또는 주소창의 설치 아이콘 / 메뉴 → 앱 설치 |
| 아이폰 · 아이패드 | Safari로 접속 → 공유 버튼 → **홈 화면에 추가** |

설치 후에는 오프라인에서도 열립니다. 데이터는 기기(브라우저)마다 따로 저장되므로, 기기를 옮길 때는 백업 파일을 이용하세요.

## 검색 · 공유 노출

- 검색엔진용 설명·키워드 메타 태그, 구조화 데이터(JSON-LD `WebApplication`), `sitemap.xml` 제공
- 카카오톡·페이스북·X 공유 미리보기 이미지(`icons/og-image.jpg`, 1200×630)
- 구글 검색 노출을 앞당기려면 [Google Search Console](https://search.google.com/search-console)에 사이트를 등록하고 `sitemap.xml`을 제출하세요. 네이버는 [서치어드바이저](https://searchadvisor.naver.com/)에서 같은 방법으로 등록합니다.

## 실행 방법

```bash
# 방법 1) 파일 바로 열기
index.html 을 브라우저로 엽니다.

# 방법 2) 로컬 서버 (Node.js 18 이상, 의존성 없음)
npm start          # http://localhost:5173
```

처음 실행하면 **샘플 데이터로 둘러보기** 버튼으로 예시 학생 4명을 불러와 모든 기능을 바로 확인할 수 있습니다.

GitHub Pages(Settings → Pages → Branch: `main` / root)로 배포하면 별도 빌드 없이 그대로 서비스됩니다.

## 테스트

```bash
npm test           # node --test tests/
```

`tests/core.test.js`에서 초·중등 교육과정 데이터, 학년 코드 변환(예전 데이터 호환), 입력값 정규화, 백업 파일 검증, 진도·평가·오답·출결 통계,
취약 단원 산출, 관리 알림, 리포트 문장, 샘플 데이터/대시보드를 검증합니다 (13개 테스트).

## 파일 구조

```
index.html          화면 뼈대 (사이드바, 하단 탭, 모달) + SEO · 공유 · 앱 메타 태그
style.css           디자인 시스템 (라이트/다크, 큰 글씨, 반응형, 인쇄용 리포트)
core.js             교육과정 · 데이터 정규화 · 분석 · 리포트 (브라우저/Node 공용)
app.js              화면 렌더링 · 해시 라우팅 · 폼 · 저장
manifest.webmanifest 앱(PWA) 정보: 이름, 아이콘, 시작 화면, 바로가기
sw.js               서비스 워커: 오프라인 실행, 최신 버전 자동 반영
sitemap.xml         검색엔진용 사이트맵
icons/              앱 아이콘(192·512·maskable·apple), 파비콘 SVG, 공유 이미지
server.js           로컬 실행용 정적 서버 (선택)
tests/core.test.js  core.js 단위 테스트
```

## 데이터 구조

```js
{
  app: "ok-math", version: 1,
  students: [{
    id, name, grade /* "e1"~"e6" = 초1~초6, "m1"~"m3" = 중1~중3 */, school, phone, parentPhone, goal, memo, reportNote, createdAt,
    progress: { "m2-04": { status: "todo|doing|done", level: 0~5, updatedAt } },
    tests:  [{ id, date, type, unitId, score, total, memo }],
    wrongs: [{ id, date, unitId, source, type, memo, resolved }],
    logs:   [{ id, date, attendance, homework, content, memo }]
  }]
}
```

단원 ID는 `{학년 코드}-{번호}` 형식입니다 (예: `e5-02` = 초5 약수와 배수, `m2-04` = 중2 연립일차방정식).
초등 단원은 1학기 → 2학기 순서이며, 검정 교과서 출판사마다 단원명이 조금 다를 수 있으니 필요하면 `core.js`의 `CURRICULUM`에서 수정하세요.

> 예전 버전 데이터(학년이 숫자 1~3)는 불러올 때 자동으로 중1~중3으로 변환됩니다.

## 주의

- 데이터는 사용 중인 브라우저에만 저장됩니다. 브라우저 데이터 삭제 전, 다른 기기로 옮기기 전에 **백업 파일 내보내기**를 해 주세요.
- 학생 개인정보(연락처 등)가 포함되므로 공용 컴퓨터에서는 사용 후 데이터를 삭제하세요.
